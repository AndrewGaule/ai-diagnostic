# AI Strategy and Implementation Diagnostic

A 5Ps self-assessment (Purpose, Process, People, Partners, Performance) by Aimava.

- **Live page:** https://andrewgaule.github.io/ai-diagnostic/
- `index.html` is the diagnostic (single self-contained page, no build step).
- `apps-script/Code.gs` is the Google Sheets back end (responses + dashboard).
- `SETUP.md` explains how to connect the Sheet and configure links.

To update the page, edit `index.html` (the `CONFIG` block near the top of the script) and commit. GitHub Pages republishes automatically within a minute or two.
